# 🎬 Netflix Clone (Full-Stack MERN App)

A full-stack Netflix-style web application built using the **MERN stack** with secure authentication, movie browsing, and live cloud deployment.

---

## 🌐 Live Demo

**Frontend (Vercel):**  
https://netflix-clone-gamma-pearl-12.vercel.app  

**Backend (Render):**  
https://netflix-backend-wpkq.onrender.com

---

## 🚀 Features

### 🔐 JWT Authentication
- User registration & login  
- Secure HTTP-only cookies  

### 🎥 Browse Movies
- Now Playing Movies  
- Popular Movies  
- Top Rated Movies  
- Upcoming Movies  

### 🔎 Search Movies
- Real-time movie search using TMDB API  

### 📱 Responsive UI
- Clean Netflix-style interface  

### ☁️ Production Deployment
- Frontend deployed on **Vercel**  
- Backend deployed on **Render**  
- Database hosted on **MongoDB Atlas**  

---

## 🛠 Tech Stack

### Frontend
- React.js  
- Redux Toolkit  
- Tailwind CSS  
- Axios  

### Backend
- Node.js  
- Express.js  
- MongoDB + Mongoose  
- JWT Authentication  
- bcrypt.js  

### Deployment
- **Vercel** → Frontend  
- **Render** → Backend  
- **MongoDB Atlas** → Database
